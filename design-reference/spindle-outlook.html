v0.4 · office.js help

Built for the actual Outlook fashion uses.

Most fashion brands and manufacturers don't run modern subscription Outlook — they run Outlook 2016 / 2019 / 2021 with the classic ribbon. This add-in is built on Microsoft's Web Add-ins (Office.js), which works on every version from 2016 forward, on Windows, Mac, web, and mobile, with no client install beyond a one-time admin approval.

01 — What's added to Outlook

Five injection points, all sandbox-compliant.

Ribbon"Spindle" tab + ribbon button group on the Home tab. One click opens the task pane.
Folder paneSpindle section with Today / Production board / auto-created style categories below the user's folders.
Email listInline status tags on each row (style number + stage), rendered via Outlook's category API — works on every version.
Reading paneInsight strip at the top: "14th message on this style, lab dip 8 days overdue."
Task paneSpindle box with 4 tabs — This style, Today, Board, Search — fitting in a ~360px sidebar.
02 — Why task panes (not Chrome-style overlay)

Office.js is sandboxed for a reason.

Outlook add-ins run in a sandboxed iframe, not as DOM-injected JavaScript. That's the limitation, and it's also the strength.

Limitation: no overlay drawer like Streak does in Gmail. The task pane is the canvas. Layout has to be vertical and compact.

Strength: a sandboxed add-in doesn't break when Microsoft updates Outlook. Streak-style DOM scraping works on Gmail because Google tolerates it; Microsoft enforces the sandbox precisely so admins can approve add-ins for use across thousands of seats with confidence.

03 — How it deploys to fashion brands

Three install paths, brand picks one.

AppSourceMicrosoft AppSource listing — public, IT-friendly, the standard. ~2-week review.
Centralized deployM365 admin centre push — IT pushes Spindle to all seats at the brand. Fastest path for larger customers.
SideloadUser-side install via manifest URL — for smaller brands without IT, or for trial/pilot phase.
Forward fallbackIf IT won't approve any of the above, brands forward supplier mail to a private Spindle inbox address — same backend, same style cards, no install required. Universal coverage; no customer is ever blocked.
04 — Honest trade-offs vs Gmail

Worse UX, better deployability.

GainReaches the 60% of fashion on Microsoft 365 · cross-platform (Win/Mac/web/mobile) by default · sandboxed = won't break · IT approves once
LoseLess freedom than Chrome extension · narrow task pane only · can't take over email view · slower review process · Office.js learning curve
Build~10–14 weeks for full Outlook + Gmail parity from one backend. Same parsing pipeline; just a second client.
RiskAppSource review can be picky. Microsoft has changed Outlook UI conventions multiple times — but the API surface stays stable.
