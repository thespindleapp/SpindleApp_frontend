# Spindle — Developer Bundle

**Start here → `spindle-handover-brief.md`**

That file is the map: it explains what Spindle is, and tells you which of the other files to read, in what order, and why. Don't open the others first.

## What's in this bundle

**Read first**
- `spindle-handover-brief.md` — the entry document / map
- `spindle-prd.md` — full product requirements
- `spindle-parser-loop.html` — the two-sided parser UI (open in a browser, click the buttons)

**Design references** (open in a browser)
- `spindle-screens.html` — popup, onboarding, settings, digest email
- `spindle-screen-gmail-email.html` / `spindle-screen-gmail-board.html` — Gmail client
- `spindle-style-card.html` / `spindle-today.html` / `spindle-board.html` — core app views
- `spindle-outlook.html` — Outlook add-in design

**Parser validation**
- `spindle-parser-test-kit.md` + `spindle-parser-scorecard.xlsx` — accuracy test methodology + results

**Supporting**
- `spindle-claude-code-prompt.md` — a prescriptive build proposal (stack, data model, phases) — treat as a strong starting opinion, not gospel
- `spindle-landing.html` — marketing site, for voice/positioning context
- `spindle-validation-kit.md` — customer research background
